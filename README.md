# OSTÉMIA — mises à jour

Ce dépôt contient **uniquement** les fichiers d'installation signés
d'OSTÉMIA et le fichier de version lu par l'application pour proposer une
mise à jour.

- **Aucun code source.**
- **Aucune donnée** : ni patient, ni consultation, ni document, ni
  sauvegarde, ni identifiant.

Chaque fichier d'installation est signé : l'application installée
n'accepte que les mises à jour signées par l'éditeur d'OSTÉMIA et refuse
tout autre fichier.

Les versions précédentes restent disponibles dans les « Releases » de ce
dépôt, pour un éventuel retour à la version précédente.
